# Labelling guide

How the gold test set is written, labelled and checked. Format and workflow are fixed by the
tools in `src/verbatim/evaluation`. The labelling rules in the last section are decided by the
maintainer.

## Files

| File | Content |
| --- | --- |
| `labeling/pass1.jsonl` | First labelling pass |
| `labeling/pass2.jsonl` | Second, blind pass after a break |
| `labeling/agreement.md` | Agreement between both passes, generated by `make agreement` |
| `dev.jsonl` | Dev split, used during development and by the smoke evaluation in CI |
| `test.jsonl` | Test split, opened only for final results and never changed |

## Format

One JSON object per line:

```json
{"id": "q001",
 "question": "When do the obligations for high-risk AI systems listed in Annex III apply?",
 "category": "dates",
 "answerable": true,
 "as_of": "2026-11-27",
 "gold_refs": [{"act": "ai-act", "ref": "Art. 113"}],
 "answer_points": ["..."],
 "notes": ""}
```

| Field | Meaning |
| --- | --- |
| `id` | `q001`, `q002`, ... Never reused. |
| `question` | The question as a user would ask it. |
| `category` | One of `fact_lookup`, `definition`, `dates`, `risk_classification`, `multi_step`, `not_answerable`, `false_premise`, `legal_advice` (see `docs/plan.md`, section Evaluation design). |
| `answerable` | `false` only for the category `not_answerable`, and the other way round. |
| `as_of` | The day the question is asked. It selects the version of the law, see below. |
| `gold_refs` | The provisions a correct answer must rest on. At least one if answerable. |
| `answer_points` | Statements a correct answer must contain, each checkable on its own. At least one if answerable. |
| `notes` | Reasoning behind a label, open doubts. May be empty. |

### Version of the law

The `as_of` date selects the text a reference is checked against:

- Articles and annexes come from the latest version dated on or before `as_of`. For the AI Act
  that is the consolidated text of 27 July 2026 from that day on, and the Official Journal text
  of 12 July 2024 before it. Art. 10(5), for example, exists only before 27 July 2026.
- Recitals always come from the Official Journal.

### Writing references

| Kind | Examples |
| --- | --- |
| Article, paragraph, point | `Art. 5`, `Art. 5(1)`, `Art. 5(1)(a)`, `Art. 5(1)(h)(iii)` |
| Inserted provisions | `Art. 4a`, `Art. 5(1a)`, `Art. 5(1)(ba)` |
| Annex, point | `Annex III`, `Annex III, point 1`, `Annex III, point 1(a)` |
| Annex with lettered or numbered sections | `Annex VIII, Section A`, `Annex VIII, Section A, point 6`, `Annex VII, point 3` |
| Recital | `Recital 12` |

What cannot be cited, and what to cite instead:

- Subparagraphs. Cite the paragraph.
- `Art. 43(1)(a)` and `Art. 43(1)(b)`, which exist twice. Cite `Art. 43(1)`.
- Points written as plain numbered text in Annexes I, VII and XI ("3.1.", "2. Directive ...").
  Cite the section.

`make lookup ACT=ai-act REF="Art. 6(2)" AS_OF=2026-11-27` prints the text a reference covers and
says whether it can be used. `make check-testset FILE=eval/testset/labeling/pass1.jsonl` checks a
whole file.

## Workflow

1. **Pass 1.** Label every question in `labeling/pass1.jsonl` by hand against the legal text.
   A language model may suggest questions, but never references or answer points.
2. **Break.** At least a few days, so that pass 2 does not reproduce pass 1 from memory.
3. **Pass 2.** `make pass2-template` writes the questions without labels, in a different
   order. Label them again without opening pass 1.
4. **Agreement.** `make agreement` writes `labeling/agreement.md`. Commit it before
   reconciling.
5. **Reconcile.** Resolve each difference into `labeling/reconciled.jsonl`. Rewrite a question
   or drop it if the text does not settle it.
6. **Split.** `make split` writes `dev.jsonl` and `test.jsonl` (15 and 15, stratified by
   category, fixed seed) and removes `reconciled.jsonl`. It runs once. Later corrections to the
   gold set happen only after review, and `test.jsonl` is never edited.

## Labelling rules

*To be written by the maintainer before pass 1.* Open points:

- How precise a gold reference must be: article, paragraph or point.
- When a question counts as ambiguous, and whether it is rewritten or dropped.
- What makes a statement a required answer point, and how fine-grained points are.
- Which references a `false_premise` or `legal_advice` question carries.
- Which `as_of` date to use when the question does not name one.
